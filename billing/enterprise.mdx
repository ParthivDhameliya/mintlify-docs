## What's included

### Infrastructure and performance

- **Dedicated GPU instances** — your workloads run on reserved hardware, never on shared serverless pools. No cold-start latency, no noisy-neighbour contention.
- **Unlimited workspaces** — create as many isolated environments as your teams need, each with its own model, knowledge base, system prompt, and API key.
- **Unlimited BYOG devices** — connect any number of your own GPU machines alongside or instead of cloud GPU.
- **Custom context window** — work with Neuramine to configure the token limit that fits your use case, beyond the 128 k Max default.
- **Unlimited RAG chunks and memories** — no per-request retrieval caps; index and retrieve as much of your knowledge base as each request requires.
- **Custom model hosting** — bring proprietary or fine-tuned models; Neuramine handles deployment, scaling, and versioning.

### Security and compliance

<CardGroup cols={2}>
  <Card title="AES-256 encryption" icon="lock" href="#security-and-compliance">
    Every workspace gets its own AES-256 encryption key managed by Neuramine's cloud key management infrastructure. Data at rest — conversation history, knowledge-base vectors, uploaded models — is encrypted per workspace, not per account.
  </Card>
  <Card title="6-year audit log retention" icon="clock-rotate-left" href="#security-and-compliance">
    Every request and response is written to an append-only, encrypted audit log synchronously — before the response is returned to the user. Logs are retained for six years to meet HIPAA requirements.
  </Card>
  <Card title="TLS 1.3" icon="shield-halved" href="#security-and-compliance">
    All connections to the Neuramine API and dashboard are protected by TLS 1.3. Older protocol versions are not negotiated.
  </Card>
  <Card title="Data isolation" icon="database" href="#security-and-compliance">
    Workspaces are isolated at every layer: separate schemas, separate vector collections, and separate encryption keys. No cross-workspace data leakage is possible at the infrastructure level.
  </Card>
</CardGroup>

### Access management

- **SSO / SAML** — integrate with your existing identity provider (Okta, Azure AD, Google Workspace, and any SAML 2.0-compatible IdP). Users authenticate through your existing SSO flow; no separate Neuramine passwords required.
- **Team management** — invite members, assign roles, and manage workspace access from a central admin panel.
- **Per-workspace API keys** — each workspace issues its own `nrm_sk_` key, so you can rotate or revoke access to individual environments without affecting others.

### Compliance certifications

| Standard | Coverage |

| **HIPAA** | BAA signed for healthcare accounts; 6-year audit log retention; AES-256 encryption per workspace; TLS 1.3 on all connections |

<Info>
  Neuramine's system prompt architecture enforces compliance guardrails at the infrastructure layer, not just the application layer. Layer 1 (platform) and Layer 2 (vertical) prompts cannot be overridden by any API call — this is enforced server-side.
</Info>
